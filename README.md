# .github

Community health files and the organization profile of [libmonero](https://github.com/libmonero).

| File | Purpose |
|------|---------|
| [profile/README.md](profile/README.md) | README shown at the top of the organization page |
| [CONTRIBUTING.md](CONTRIBUTING.md) | Default contributing guide for repositories without their own |
| [SECURITY.md](SECURITY.md) | Default security policy for repositories without their own |

A repository that has its own `CONTRIBUTING.md` or `SECURITY.md` keeps using it.
